Per-vendor enrichment — step by step
Step 1 Google Discovery Apify Google Search → cs_vendor_candidates

Discover new vendors from Google search. Results land in cs_vendor_candidates for review before promotion.

Step 2 Three-Tier Website Crawl HTTP / Apify RAG / Apify WCC → vendor_pages + crawl_tier{1,2,3}_result

Crawl the vendor site using the cheapest successful tier. Pages stored in vendor_pages. Tier summary written to crawl_tier{N}_result.

Step 3 Datagma Firmographic Datagma via RapidAPI → crawl_datagma_result

Enrich founded, hq_address, company_size, funding_stage, total_funding, ceo_name, revenue from Datagma. Requires RAPIDAPI_KEY.

Step 4 G2 Enrichment G2 via RapidAPI → crawl_g2_result

Enrich g2_rating, g2_review_count, g2_categories, g2_market_segment from G2 Data API. Hit rate ~33%. Requires RAPIDAPI_KEY.

Step 5 LLM Extraction (GPT-4o / Ollama fallback) GPT-4o → Ollama + nomic-embed-text → crawl_llm_result + vendor_page_embeddings

Crawl → chunk → embed → RAG → extract mission, icp, lifecycle_stages, key_features, integrations etc. Uses GPT-4o with Ollama (Mistral) as local fallback. Requires vendor_pages rows.

Run Step 2 (Tier Crawl) first — vendor_pages has 0 rows for this vendor.
Step 6 Clean Merge Python merge_module → cs_vendors main columns + source_field_map

Apply COALESCE priority rules across all crawl_*_result columns. Write winning values to main schema. Never overwrites existing values with null.

Step 7 Batch LLM Enrichment — All Vendors GPT-4o (OpenAI) → directory_dataset.json (incremental)

Runs the full crawl → embed → GPT-4o extraction pipeline for every vendor not yet enriched. Saves progress after each vendor — safe to interrupt and resume. ~$0.05–0.10 per vendor.

Step 8 Trustpilot Enrichment Trustpilot (HTTP scrape) → trustpilot_rating, trustpilot_review_count

Scrapes the Trustpilot review page for the vendor domain. Fills trustpilot_rating and trustpilot_review_count. Triggered via the csp-trustpilot-enrichment n8n workflow.

Step 9 Feature Depth Enrichment Help site crawl + GPT-4o mini → feature_depth_score, feature_signals

Crawls vendor help_center_url (fallback: developer_docs_url), extracts feature taxonomy across 6 dimensions (integrations, automation, reporting, onboarding, collaboration, API/dev), computes category-relative feature_depth_score (0–100) and feature_signals list.

Step 10 Export Dataset → Vercel Supabase → JSON → docs/website/data/directory_dataset.json

Pull latest vendor data from Supabase and write the static directory_dataset.json that powers the Vercel browse + vendor pages. Run after any enrichment to publish changes.
